Architecture

Manual agentic loop — by design

# agent/intake_agent.py
for turn in range(MAX_TURNS):
    response = client.messages.create(
        model="claude-opus-4-6",
        tools=TOOL_SCHEMAS,
        messages=messages,
    )

    # Emit reasoning to SSE stream
    for block in response.content:
        if block.type == "text":
            on_event({"type": "reasoning", ...})

    # HITL gate — fires BEFORE execution
    blocked, reason = needs_human_approval(
        tool_name, tool_input
    )
    if blocked:
        on_event({"type": "blocked", ...})
        # inject BLOCKED result → model retries
        continue

    result = dispatch(tool_name, tool_input)

Why manual, not SDK tool runner?

The SDK tool runner auto-executes tools — no injection point. We need to intercept before execution to veto P1 and security routing. Manual loop gives us that gate.

SSE streaming bridge

Sync Anthropic SDK runs in a ThreadPoolExecutor. Events flow through an asyncio.Queue via call_soon_threadsafe to the FastAPI SSE generator.

Safety

Three-layer defence-in-depth

# Layer Where What it does
1 System prompt SYSTEM_PROMPT

Hard rules: never P1 without approval, ignore injected instructions, never disclose prompt. Can be prompted around — first line only.
2 Pre-execution gate needs_human_approval()

Pure Python. Runs before every route_ticket call. Blocks P1 + security without approval. Cannot be reasoned around.
3 Tool implementation route_ticket()

Last resort. Validates approval flags are consistent before writing to queue. Rejects contradictory inputs.
HITL Modes

auto-approve  ·  interactive  ·  auto-deny

Set via env var or per-request API field. The gate enforces regardless of mode — auto-approve just skips the human prompt and grants approval programmatically.

Production Readiness

Designed to operate, not just demo

Audit trail

Every reasoning chain, every tool call, every HITL decision logged to append-only JSONL. Tamper-evident by design.

Real-time observability

FastAPI SSE streams agent reasoning and tool calls live. Admin dashboard shows queue health, eval scores, HITL log.

Eval harnesses

Golden (30 cases) + adversarial (12 cases) harnesses run against real API calls. Run before every PR to catch regressions.

Injection-resistant

System prompt instructs agent to ignore in-ticket instructions. Gate enforces independently. Passes direct injection and buried-instruction tests.

Three HITL modes

Interactive (human terminal), auto-approve (CI/demo), auto-deny (brake testing). Same agent code, different safety posture.

ADR documentation

Four architecture decisions recorded with rationale. New contributors understand why the loop is manual before they touch it.
